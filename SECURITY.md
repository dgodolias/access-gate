# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub's private vulnerability reporting on this
repository ("Security" tab → "Report a vulnerability"). Include the affected
version, a minimal reproduction and the impact you see. You will get an
acknowledgement within a few days and a fix or a workaround as soon as one is
ready. Credit is given in the changelog unless you prefer otherwise.

## Scope

`access-gate` is a shared-password gate for pre-release and internal sites.
It is **not** a user authentication system. See "Threat model and known
limits" in the README before relying on it for anything sensitive.

## Supported versions

Only the latest release line receives fixes.
